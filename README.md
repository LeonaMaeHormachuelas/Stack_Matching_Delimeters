# Stack_Matching_Delimeters
For School Purposes

Stack - Matching Delimiters (Java)

Run (JDK 11+):
  cd src
  javac StackDelimiterChecker.java StackDelimiterCheckerTrace.java
  java StackDelimiterChecker          (Task 2 - checker)
  java StackDelimiterCheckerTrace     (Task 4 - checker with stack trace)
Type a sequence and press Enter; type 'exit' to quit.
